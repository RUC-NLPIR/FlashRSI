Get started

Run your first self-improvement experiment

FlashRSI gives an RSI method a controlled resource scope, runs each candidate through a native agent harness, and measures the resulting trajectories on a benchmark.

Open the quickstartUnderstand the design
Terminalquickstart
export TARGET_API_KEY="..."
export WORKER_API_KEY="..."

flashrsi run \
  --config examples/quickstart.yaml \
  --model gpt-5-mini \
  --worker-model gpt-5-mini
●
Two model roles, one experimentThe Target solves benchmark tasks. The Worker proposes edits or changes candidate files. Configure them independently.

Choose the pieces

Every run combines four explicit inputs. You can change one without rewriting the runner.

Method

12 RSI algorithms

From instruction search to broad harness evolution.

Target

3 native harnesses

MiniAgent, Claude Code, and Codex resources.

Evidence

30 benchmarks

Task outcomes, metrics, and trajectories.

Freeze and evaluate

Use flashrsi evaluate --snapshot … to test a selected or intermediate Snapshot without continuing evolution.

A complete candidate, a scoped edit

A Snapshot is a tagged resource tree. Algorithms edit a declared view; the harness executes the complete candidate so the surrounding tools and runtime remain meaningful.
