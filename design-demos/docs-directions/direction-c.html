01Install and make a run

Use Python 3.11 or newer. Python 3.12 is the practical default when a benchmark needs Harbor or Docker.

First run. Install the package, set independent Target and Worker credentials, then run the bundled SearchQA example from the repository root.
Terminal / quickstart.yaml
flashrsi run \
  --config examples/quickstart.yaml \
  --model gpt-5-mini \
  --worker-model gpt-5-mini
