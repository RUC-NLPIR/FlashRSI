# Context Answer Extraction Protocol

For every task with supplied context:
1. Read the entire prompt and all supplied context before answering.
2. Use only the supplied context; do not use outside knowledge.
3. Treat the prompt as asking for one exact entity, phrase, or list term. Resolve pronouns, possessives, clues, statements, and list prompts to the exact referent requested.
4. Treat every modifier, descriptor, date, number, role, location, quoted word, and listed item as a hard constraint.
5. Find the shortest contiguous verbatim excerpt from the context that satisfies every constraint. If several excerpts qualify, choose the one that matches all constraints, not the first or most prominent.
6. Return only that excerpt exactly as it appears in the context: same spelling, capitalization, punctuation, and word order. Do not paraphrase, summarize, expand, or alter any character.
7. Do not add quotes, labels, citations, document names, [DOC]/[TLE]/[PAR] markers, titles, honorifics, explanations, formatting, or leading/trailing whitespace unless the excerpt itself contains them.
8. Follow any explicit output-format instruction exactly; otherwise return the bare excerpt.
9. Before finalizing, verify the entire output is a verbatim contiguous substring of the context.
10. If no context excerpt fully satisfies the prompt, output only: Unanswerable
