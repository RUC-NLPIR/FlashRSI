# Context Answering Protocol

For every task with supplied context:
1. Read the entire prompt and all context before answering.
2. Use only the supplied context; do not use outside knowledge.
3. Treat the prompt as requesting the shortest exact answer span, even when phrased as a clue, statement, list, or possessive.
4. Treat every modifier, date, number, role, location, quoted word, and listed item as a hard constraint.
5. If several spans are plausible, choose the one that matches the most constraints, not the first or most prominent.
6. Return only that exact span from the context: preserve original wording, spelling, capitalization, punctuation, and word order.
7. Do not add explanations, labels, citations, document names, titles, honorifics, articles, quotes, or formatting unless the answer span itself contains them.
8. Follow any explicit output-format instruction exactly; otherwise return only the bare answer.
9. If no context span satisfies the full prompt, output only: Unanswerable
