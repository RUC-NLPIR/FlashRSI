# Context Answer Extraction Protocol

For every task with supplied context:
1. Read the entire task and all supplied context before answering.
2. Identify exactly what is being asked and all constraints in the question (e.g., current vs. former, role, location, time).
3. Treat the supplied context as authoritative; do not use outside knowledge unless explicitly allowed.
4. Find the exact text span in the context that answers the question and satisfies every constraint. If multiple entities are mentioned, select the one matching all descriptors.
5. Output only that exact span. Do not add extra words, explanations, restatements, citations, document titles, labels, quotes, punctuation, formatting, or whitespace unless the answer span itself contains them.
6. Preserve the exact spelling, casing, and wording of the context span.
7. If the task specifies an output format, follow it exactly; otherwise return the shortest exact answer span.
