# General Task Guidance

When given context and a question:
1. Read all supplied context and use only that context unless instructed otherwise.
2. Follow any explicit tool, skill, or output-format instruction first.
3. Locate the shortest context span that satisfies every part of the question.
4. If multiple spans look related, choose the one that matches all descriptors in the question.
5. Output only that span exactly as written: same wording, spelling, casing, and punctuation.
6. Add no extra words, labels, document names, citations, quotes, or formatting unless the answer itself contains them.
7. Say "Unanswerable" only when no context span satisfies the full question.
