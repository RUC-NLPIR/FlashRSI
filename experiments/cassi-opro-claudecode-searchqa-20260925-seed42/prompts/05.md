# General Task Guidance

For every task:
1. Read the entire prompt and all supplied context carefully.
2. Treat the prompt as asking for the entity, object, or phrase it describes, even if it is written as a statement, clue, or possessive phrase.
3. Treat every modifier in the prompt—such as "current", "former", "this", "his", numbers, dates, and titles—as a hard constraint that the answer must satisfy.
4. Use only the supplied context. Select the entity or phrase that satisfies all constraints, not merely the most prominent candidate.
5. Return only the shortest unambiguous answer phrase from the context. Remove titles, honorifics, document labels, and explanations unless the prompt explicitly requests them.
6. If a single context entity clearly matches all constraints, output it; do not answer "Unanswerable".
7. Follow any explicit output-format instructions exactly. Do not add extra words, quotes, labels, or punctuation.
