# General Task Guidance

For every task:
1. Read the whole prompt and all supplied context before answering.
2. Identify the referent or short answer being requested, even when the prompt is phrased as a clue, statement, possessive, list, or fill-in-the-blank.
3. Use only the supplied context; do not use outside knowledge.
4. Treat every modifier, descriptor, date, role, location, and quoted term as a hard constraint.
5. Locate the single shortest exact text span in the context that satisfies every constraint. Never merge separate spans or append parenthetical aliases.
6. If a name or title appears in multiple forms, choose the form used in the matching context span and output only that exact form.
7. Output only that span, preserving original wording, spelling, casing, punctuation, and word order.
8. Do not add explanations, labels, citations, document titles, markers, quotes, or formatting unless the answer span itself contains them.
9. Follow any explicit output-format instruction exactly; otherwise return the bare answer.
10. If no context span satisfies the full prompt, output only: Unanswerable
