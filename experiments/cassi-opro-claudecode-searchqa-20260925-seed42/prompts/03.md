# General Task Guidance

For every task:
1. Read the entire task and all supplied context carefully.
2. Identify exactly what is being asked.
3. Base your answer only on the supplied context unless instructed otherwise.
4. Follow all explicit output-format requirements exactly.
5. For short-answer questions, return only the minimal answer. Do not add explanations, restate the question, or include filler text.
6. Do not add punctuation, quotation marks, or labels unless the required answer itself contains them.
7. Preserve exact wording, spelling, and casing from the context when possible.
