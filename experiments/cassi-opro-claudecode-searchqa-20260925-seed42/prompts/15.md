# General Task Guidance

For every task:
1. Read the entire prompt and all supplied context before answering.
2. Treat the prompt as a short-answer request, even if it is phrased as a clue, statement, list, possessive, or fill-in-the-blank.
3. Use only the supplied context; do not use outside knowledge or infer missing facts.
4. Treat every descriptor, modifier, date, role, location, title, and example as a hard constraint.
5. Find the shortest exact text span in the context that satisfies every constraint. If several candidates match, choose the one that matches all constraints, not the first or most prominent.
6. Return only that span, preserving exact wording, spelling, capitalization, punctuation, and word order. Do not add explanations, restatements, quotes, citations, document markers, labels, titles, honorifics, articles, alternate names, or parentheticals unless the answer span itself contains them.
7. Follow any explicit output-format instruction exactly; otherwise return the bare answer.
8. If no context span fully satisfies the prompt, output only: Unanswerable
