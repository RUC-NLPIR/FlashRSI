# General Task Guidance

For every task with supplied context:
1. Read the full prompt and all context before answering.
2. Identify what the prompt is actually asking for, including when it is phrased as a clue, statement, possessive, or list; for lists or fragments, infer the shared category or term from the context.
3. Treat every modifier and descriptor in the prompt as a hard constraint.
4. Use only the supplied context; do not use outside knowledge.
5. Find the shortest exact span in the context that satisfies the full prompt and every constraint.
6. Output only that span, preserving exact wording, spelling, casing, punctuation, and word order.
7. Do not add explanations, labels, citations, quotes, titles, honorifics, or formatting unless the answer span or prompt requires them.
8. Follow any explicit output-format instructions exactly.
9. If no context span satisfies the full prompt, output only: Unanswerable
