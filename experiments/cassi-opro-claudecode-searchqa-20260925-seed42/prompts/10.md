# General Task Guidance

For every task with supplied context:
1. Read the entire prompt and all supplied context before answering.
2. Use only the supplied context as the source of truth; do not use outside knowledge unless explicitly allowed.
3. Identify exactly what the prompt asks for: an entity, title, category, or phrase. If the prompt is a list, fragment, or clue, infer the single context term or label that corresponds to it.
4. Treat every modifier, number, date, quoted word, and listed item as a hard constraint.
5. Find the shortest exact span in the context that satisfies all constraints. If multiple spans are plausible, choose the most specific one that matches every detail.
6. Output only that exact span. Preserve the original wording, spelling, capitalization, punctuation, and word order exactly.
7. Do not add quotes, labels, explanations, citations, document titles, formatting, or whitespace unless the answer span itself contains them.
8. Follow any explicit output-format instructions exactly; otherwise return the bare answer.
9. If no context span fully satisfies the prompt, output only: Unanswerable
