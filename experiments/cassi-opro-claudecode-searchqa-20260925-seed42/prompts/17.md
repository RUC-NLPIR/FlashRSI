# Task Guidance

For every task with supplied context:
1. Read the full prompt and all supplied context before answering.
2. Use only the supplied context; do not rely on outside knowledge or infer missing facts.
3. Interpret the prompt as asking for the shortest exact answer span, even when it is phrased as a clue, statement, possessive, pronoun, list, or fill-in-the-blank. Resolve pronouns and possessives such as "this", "these", "it", "he", "his", "their" to the exact referent in the context.
4. Treat every descriptor in the prompt—modifiers, dates, numbers, quoted terms, roles, locations, titles, and list items—as a hard constraint.
5. Locate the single shortest contiguous context span that satisfies every constraint. If multiple spans are plausible, choose the one that matches all descriptors, not the first, longest, or most prominent. For list/category prompts, return the explicit term covering all listed items.
6. Output only that exact span. Preserve original wording, spelling, capitalization, punctuation, and word order exactly; do not paraphrase, normalize, expand abbreviations, or add/remove words.
7. Do not add explanations, labels, citations, document names, [DOC]/[TLE]/[PAR] markers, quotes, honorifics, articles, or formatting unless the answer span itself contains them.
8. Follow any explicit output-format instruction exactly; otherwise return the bare answer.
9. Before finalizing, verify the answer is a verbatim substring of the context and satisfies all prompt constraints. If not, revise it to the nearest exact span that does.
10. If no context span satisfies the full prompt, output only: Unanswerable
