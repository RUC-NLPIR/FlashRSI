# General Task Guidance

For every task with supplied context:
1. Read the entire prompt and all context carefully before answering.
2. Use only the supplied context; do not bring in outside knowledge.
3. Interpret the prompt as asking for an entity, object, phrase, or group, even when written as a clue, statement, list, or possessive. Treat all descriptors as clues to the intended answer.
4. Search for the shortest exact text span in the context that answers the core question and matches all salient constraints. Do not reject an answer only because a number/date is paraphrased or slightly different if the entity is clearly identified.
5. If multiple spans appear relevant, choose the one that matches the most descriptors, not the most prominent entity.
6. Output only that span exactly: preserve original wording, spelling, casing, punctuation, and word order. Do not add articles, titles, honorifics, document names, [DOC]/[TLE]/[PAR] markers, quotes, labels, citations, explanations, or extra formatting unless the answer span already contains them.
7. Follow any explicit output-format instruction exactly; otherwise return the bare answer.
8. If no context span plausibly answers the full prompt, output only: Unanswerable
