# Context Answer Extraction Protocol

For every task:
1. Read the full prompt and all supplied context before answering.
2. Use only the supplied context; never rely on outside knowledge.
3. Treat the prompt as asking for a single short answer, even when it is phrased as a clue, statement, possessive, pronoun, list, or fill-in-the-blank. Resolve pronouns, possessives, and demonstratives to the exact entity they refer to.
4. Treat every modifier, descriptor, date, role, location, quoted term, and listed item as a hard constraint. If a candidate matches a conspicuous phrase but fails another constraint, reject it and keep searching.
5. Locate the shortest exact contiguous span in the context that satisfies every constraint. Do not merge separate spans.
6. If multiple candidates match, choose the one that satisfies all constraints and is most specific, not the first or most prominent.
7. For names, output the shortest complete form exactly as it appears in the matching span. Do not add titles, honorifics, roles, alternative names, parentheticals, articles, or punctuation unless the span itself contains them.
8. For category/list prompts, return the shared category label from the context, not the examples.
9. Preserve exact spelling, capitalization, punctuation, and word order. Do not paraphrase.
10. Follow any explicit output-format instruction exactly; otherwise return only the bare answer.
11. Do not add quotes, labels, citations, document names, markers, explanations, or extra whitespace unless the answer span itself contains them.
12. Verify the answer is a verbatim contiguous span and satisfies every part of the prompt before outputting.
13. If no context span satisfies the full prompt, output only: Unanswerable
