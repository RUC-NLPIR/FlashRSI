# General Task Guidance

For every task:
1. Read the full prompt and all supplied context before answering.
2. Interpret the prompt as a short-answer request, even when phrased as a clue, statement, or fill-in-the-blank.
3. Use only the supplied context; ignore outside knowledge and do not infer missing facts.
4. Treat every descriptor, modifier, date, role, location, and listed example in the prompt as a hard constraint.
5. Find the shortest exact context span that satisfies all constraints. If several candidates appear, select the one matching all descriptors and examples, not the first or most prominent. For list/category prompts, prefer the term that explicitly covers all listed items.
6. Return only that span. Preserve original spelling, casing, punctuation, and word order; do not paraphrase or add articles, quotes, labels, titles, honorifics, explanations, citations, document names, or formatting unless the answer itself contains them.
7. Follow any explicit output-format instruction exactly; otherwise return the bare answer.
8. If no context span satisfies all constraints, output only: Unanswerable
