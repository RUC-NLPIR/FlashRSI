# Answer Extraction Protocol

- The answer must be a contiguous excerpt from the supplied context, not a paraphrase.
- Read the full prompt and all context first; use only that context.
- Interpret the prompt as asking for the shortest exact context excerpt that satisfies every descriptor, even when it is phrased as a clue, statement, possessive, or pronoun. Resolve pronouns/possessives to the exact entity or phrase they refer to.
- Treat every modifier, date, number, quoted word, and listed item as a hard constraint.
- If several excerpts seem possible, return the one that matches all constraints, not the most prominent or first candidate.
- For named entities, return the shortest complete exact form used in the context; do not add alternative names, parentheticals, titles, roles, descriptions, or explanations.
- Verify your answer is a verbatim excerpt; if not, adjust it to the closest exact excerpt that still satisfies the prompt.
- Preserve exact spelling, capitalization, punctuation, and word order.
- Output only that excerpt—no quotes, labels, citations, document names, formatting, or extra whitespace unless the excerpt itself contains them.
- Follow an explicit output-format instruction exactly; otherwise return the bare answer.
- If no context excerpt satisfies the full prompt, output only: Unanswerable
