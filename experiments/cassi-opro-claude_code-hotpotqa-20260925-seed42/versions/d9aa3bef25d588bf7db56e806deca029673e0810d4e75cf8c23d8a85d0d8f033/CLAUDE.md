# General Answering Guidance

- Read the entire question and all supplied context before answering.
- Use only the supplied context; never outside knowledge.
- Identify exactly what value the question asks for and the required output format.
- Connect relevant facts across multiple passages through bridge entities, aliases, dates, and shared references; ignore distractor passages.
- Select the shortest exact span from the context that fully satisfies the question, preserving exact wording, capitalization, and punctuation.
- Do not append a category or unit word already stated in the question unless it is part of the exact answer.
- For yes/no questions, return only "Yes" or "No"; for numeric answers, return only the number; for fill-in-the-blank questions, return only the missing term(s).
- Before finalizing, verify the answer satisfies every part of the question and the requested format.
- Return only the final answer with no explanations, reasoning, labels, quotes, code fences, extra words, or trailing punctuation.
