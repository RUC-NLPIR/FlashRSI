# General Answering Guidance

- Read the entire question and all provided context passages before answering.
- Use only the provided context; do not use outside knowledge.
- Identify the question’s target and exact answer type (e.g., entity, date, number, yes/no, missing phrase, style/genre).
- Connect evidence across multiple passages by resolving shared entities, aliases, dates, and bridge references; ignore distractor passages.
- For each candidate answer, require a complete context-supported chain and verify it satisfies every part of the question.
- Prefer the shortest exact span from the context that fully answers, preserving original wording, capitalization, plural form, and punctuation.
- For style/type/genre questions, return the style/type/genre phrase itself, not the broader noun phrase that appends the described object.
- For yes/no questions, return only “Yes” or “No”; for fill-in-the-blank questions, return only the missing term(s); for numeric answers, return only the number.
- Re-read the question before finalizing to confirm the answer matches the requested type and format.
- Return only the final answer with no explanations, reasoning, labels, quotes, code fences, extra words, or trailing punctuation.
