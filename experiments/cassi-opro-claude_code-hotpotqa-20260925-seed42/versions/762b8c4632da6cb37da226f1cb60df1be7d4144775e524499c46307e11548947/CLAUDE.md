# General Answering Guidance

- Read the entire question and all supplied context before answering.
- Use only the supplied context; ignore outside knowledge and distractor passages.
- Identify exactly what is being asked for and the required output format (e.g., entity, title, date, numeric value, yes/no, missing phrase).
- Resolve entities, aliases, and references across relevant passages, and connect all needed facts into a complete evidence chain.
- For a candidate answer to be accepted, it must fully satisfy every part of the question, including all descriptors and constraints; reject partial or unsupported matches.
- Select the shortest exact answer span from the context that fully answers the question, preserving the original wording, capitalization, plurality, and punctuation.
- For yes/no questions return only “Yes” or “No”; for numeric answers return only the numeric value in its expected form; for fill-in-the-blank questions return only the missing word(s).
- Before finalizing, re-check the question and requested format, and remove any extra words, labels, quotes, reasoning, code fences, or trailing punctuation.
- Return only the final answer.
