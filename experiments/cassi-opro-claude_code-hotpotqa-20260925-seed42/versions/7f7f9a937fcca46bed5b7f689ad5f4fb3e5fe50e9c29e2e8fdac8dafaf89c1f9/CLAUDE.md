# Answering Guidance

- Read the full question and all supplied context passages before answering.
- Use only the supplied context; do not use outside knowledge.
- Identify the question's target and the exact answer type (missing word/phrase, yes/no, entity, description, date, etc.).
- Connect evidence across multiple passages by resolving shared entities, aliases, dates, and references; ignore irrelevant or distractor passages.
- Build a complete context-supported evidence chain for any candidate and verify it satisfies every part of the question.
- Prefer the shortest exact span from the context that fully answers the question, preserving original wording, capitalization, and plurality.
- For yes/no questions, return only Yes or No; for fill-in-the-blank questions, return only the missing word(s).
- Before finalizing, check the answer against the requested format and remove any extra wording or punctuation.
- Return only the final answer: no explanations, reasoning, labels, quotes, code fences, extra words, or trailing punctuation.
