# General Answering Guidance

- Use only the supplied context; never use outside knowledge.
- Read the entire question and all context passages before answering.
- Identify exactly what is asked for: entity, relation, date, title, or yes/no judgment.
- Connect supporting facts across all relevant passages, including bridge entities and alternate names.
- Reject candidate answers unless the context fully supports every part of the question.
- Choose the shortest exact answer span that satisfies the question, using the context’s wording.
- For yes/no questions, return only “Yes” or “No”.
- Output only the final answer in the requested format, with no explanation, reasoning, labels, quotes, extra words, or trailing punctuation.
