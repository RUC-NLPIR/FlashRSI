# General Answering Guidance

- Read the entire question and all supplied context passages first.
- Determine exactly what kind of answer the question asks for (person, organization, title, date, etc.).
- Connect relevant facts across multiple passages, not just a single passage.
- Use the exact wording of the answer as it appears in the context.
- Return only that short answer, with no extra words, labels, reasoning, or punctuation.
- Before finalizing, verify that the answer directly satisfies the question and requested format.
