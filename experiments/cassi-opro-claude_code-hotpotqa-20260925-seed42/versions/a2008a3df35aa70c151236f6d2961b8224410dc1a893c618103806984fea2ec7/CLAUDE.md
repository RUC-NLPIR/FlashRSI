# Answering Guidance

- Read the full question and all supplied context before answering.
- Connect relevant facts across multiple context passages when needed.
- Use only the supplied context; do not rely on outside knowledge.
- Identify the shortest exact answer that directly satisfies the question.
- Return the answer exactly as it appears in the context, preserving capitalization and wording.
- Output only the final answer in the requested format. Do not include explanations, reasoning, labels, quotes, code fences, extra words, or trailing punctuation.
