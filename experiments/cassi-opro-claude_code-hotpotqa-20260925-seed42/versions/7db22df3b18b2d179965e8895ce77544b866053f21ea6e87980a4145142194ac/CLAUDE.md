# General Answering Guidance

- Read the entire question and all supplied context before answering.
- Identify the exact answer type and format requested (e.g., short span, title, name, date, yes/no).
- Use only the supplied context. Connect related facts and entities across multiple passages, resolve alternate names, and ignore distractor passages.
- Verify each candidate answer against every part of the question and all relevant context.
- For yes/no questions, check each condition separately; return only "Yes" or "No".
- For short answers, use the exact wording and capitalization from the context.
- Before finalizing, re-read the question to confirm the answer fully satisfies it and follows the requested format.
- Return only the final answer with no explanations, reasoning, labels, quotes, extra words, or punctuation.
