# Restricted evolution and RRSI archive publication — 2026-10-27

All 23 archive groups are uploaded to the authorized GitHub Draft Release and verified. The independent publication branch is ready for human review and merge; the Release remains a draft. Git clone retrieves metadata, not archive attachments.

The scope comprises 12 restricted evolution groups (AHE, DarwinX and MetaHarness across SearchQA, HotpotQA, AppWorld and Terminal), eight original RRSI groups (four benchmarks and two harnesses), and three external checkpoint/cache/trajectory closures. These are archive groups, not 23 new successful experiments. Historical failed and cancelled attempts, costs and protocol decisions remain part of the preserved evidence.

Each artifacts.json records ordered archive parts, whole-archive SHA-256, asset IDs and checksums. Download through the draft Release with repository access, verify part hashes, concatenate in the recorded order, then verify the whole-archive hash. All assets were checked against GitHub server size and SHA-256; only the small pilot was fully downloaded for additional readback. Full download of every large attachment is not claimed.

The final three large groups were scanned and streamed directly from their original development machines. No new local archive copies or large parts were generated. Original experiments and original RRSI archives remain unchanged. Exact historical incomplete CIFAR downloads and independently verified public-string scan exceptions are disclosed in the per-group verification files; an incomplete historical nested download is not claimed to be a valid archive. No new model, Worker, grading or candidate-selection calls were made.

Source machines have not been deleted or approved for retirement. SpreadsheetBench2 and any unrelated machine contents remain outside this archival retirement decision.
