# Experiment explorer

Open an experiment to inspect its candidate decisions, recorded edit rationale, resource changes, development scores, and runtime logs.

## Available experiments

| Experiment | Target harnesses | Records |
| --- | --- | --- |
| [SkillOpt × SearchQA](./skillopt-searchqa.md) | MiniAgent, Claude Code | 43 candidate decisions per harness; skill comparisons and runtime logs |

The current explorer does not display test results. It preserves invalid edits and rejected candidates alongside accepted updates. Runtime progress logs are distinct from complete model conversation transcripts.

To add an experiment, see [maintaining the explorer](../development/docs-site.md#experiment-explorer).
