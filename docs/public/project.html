Evidence / 04

Every row has a run behind it

FlashRSI keeps the configuration, Snapshot lineage, trajectories, metrics, usage, and task artifacts together.

  1. Capture the baseline

    Build the initial AgentSnapshot and record the resources available to the method.

  2. Search inside scope

    Use Target feedback or Worker edits to produce candidate resource versions.

  3. Run the complete candidate

    Execute the candidate through its native harness and keep the trajectory.

  4. Score and select

    Grade the trajectory, select a Snapshot, and evaluate it on the destination split.

Snapshot lineageParent, changed resources, roles, and version identity.
Target and WorkerTask answers, proposals, reflections, and selection decisions.
Run artifactsRedacted config, metrics, usage, logs, and task files.
