# FlashRSI cover

The animated cover takes visual cues from React Bits [Threads](https://reactbits.dev/backgrounds/threads): fine blue-white strands gather and fan out while the wordmark stays still. The plain dark background and open space keep the illustration separate from the typography. [Floating Lines](https://reactbits.dev/backgrounds/floating-lines) inspired a quieter alternative with two crossing ribbons, saved as [cover-floating.gif](cover-floating.gif).

These are original offline curve renderings. Their sine and cosine motion repeats over seven seconds, allowing the GIFs to loop continuously. The README uses the GIF so the effect plays directly on GitHub. The renderer includes no React Bits component or shader source.

The demo shares the background and typography. Three open reels use a subtle selected row. Four borderless plots draw thin colored lines. The demo stays before Quick start; its curves are illustrative.

The FlashRSI wordmark uses Space Grotesk Bold with close spacing. Its glyphs are outlined in the static SVG to preserve the typeface across browsers. The bundled font and its SIL Open Font License are in [assets/fonts](../fonts/).

Run `uv run --script scripts/render_readme_cover.py` to regenerate the main [GIF](cover.gif), [SVG](cover.svg), and [PNG](cover.png). Add `--style floating` to regenerate the alternative, or `--poster-only` to render stills. All assets are self-contained. The demo GIF is generated by [render_readme_hero.py](../../scripts/render_readme_hero.py).
