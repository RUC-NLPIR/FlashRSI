# FlashRSI cover

The cover uses a plain near-black background, a large white wordmark, and three paths that branch apart and converge. The motif suggests exploring candidate changes and selecting a version to carry forward. A light-blue path leads into a small warm-orange continuation; quieter branches give it context. Most of the canvas is open space.

The demo shares the background and typography. Three open reels use a subtle selected row. Four borderless plots draw thin colored lines. The demo stays before Quick start; its curves are illustrative.

The FlashRSI wordmark uses Space Grotesk Bold with close spacing. Its glyphs are outlined in the cover SVG to preserve the typeface across browsers. The bundled font and its SIL Open Font License are in [assets/fonts](../fonts/).

Run `uv run --script scripts/render_readme_cover.py` to regenerate [cover.svg](cover.svg), or edit the SVG directly. [cover.png](cover.png) is a rasterized preview of the same SVG. The SVG is static and self-contained. The demo GIF is generated by [render_readme_hero.py](../../scripts/render_readme_hero.py).
