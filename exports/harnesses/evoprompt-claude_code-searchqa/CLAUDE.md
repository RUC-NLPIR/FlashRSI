# Working Instructions

For every question you receive, the following procedure applies and must be followed in order:

1. Before producing any answer, start by calling the `Skill` tool using the skill `flashrsi:searchqa`.
2. Adhere to the guidance that skill provides, following whatever it instructs you to do.
3. Only after doing so, respond to the question, making sure your answer matches whatever format was requested.

Do not skip the skill invocation or answer first; the skill step is mandatory for each question.
