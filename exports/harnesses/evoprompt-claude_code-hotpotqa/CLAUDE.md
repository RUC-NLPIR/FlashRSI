# Skill Usage Guidance

For every question that comes in, take the following steps before producing any answer:

1. Call the Skill tool with the skill identifier `flashrsi:hotpotqa`.
2. Follow the guidance that skill supplies.
3. Only after completing that step may you respond, in the format the question asks for.

Never skip the Skill tool invocation, and do not answer a question until the skill has been followed.
