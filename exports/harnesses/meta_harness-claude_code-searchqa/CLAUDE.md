Core rules (always apply):
- Answer using only the supplied context, and return only the short answer itself: no explanation, no markdown, no preamble, no "Answer:", no "What is..." / "Who is..." phrasing, no trailing punctuation unless it is part of the answer.
- The questions are usually Jeopardy-style clues phrased as statements that describe an entity. Name that entity. Do not answer True/False/Yes/No unless the question explicitly asks for a true/false or yes/no answer.
- Prefer the shortest exact phrase that uniquely answers the clue. Do not over-expand a person's name or a work's subtitle, and do not shorten a full proper name when the full form is the common name. Match singular/plural and articles.
- Use the exact spelling from the most relevant context passage: `Pitti Palace` not `Palazzo Pitti`; `phyllo` not `Filo`; `Showboat` not `Show Boat`; `Lake Superior` not `Superior` when the clue lists the Great Lakes; `Studio 60` not `Studio 60 on the Sunset Strip`; `Forbes magazine` not `Forbes` when the clue says someone began publishing a journal; `Pituitary gland` not `pituitary` for "this gland"; `manatee` not `Florida manatee` unless the exact variety is asked; `falcon` not `Maltese Falcon` for "one of these birds"; `Sirius` not `Sirius Satellite Radio` for the satellite-radio company.
- Also use the exact form: `strawberries` not `strawberry` when the festival passage uses the plural; `man-hour` not `man hour`/`Man-hours` for the industrial work unit; `C` not `Vitamin C` when the clue says "this vitamin"; `Bananas` not `coffee` for a "fruit crop" export clue; `Trent Lott` not `Roger Wicker` when the clue says a GOP leader is "first & foremost a senator from Mississippi".
- If a J! Archive/trivia passage shows a bare answer line after the clue, copy that exact form (for example `Clark`, `Genet`).
- For a bare proper name or list with no "this/these" or verb, answer the associated broader entity (country, state, show, band), not the named entity itself — except a bare comma-separated list of place names, where you should pick the member of the list rather than the category.
